# 软考软件设计师 · 8周备考与极限冲刺系统

> 面向软考中级 **软件设计师（Soft Designer）** 考生的全栈现代化交互式备考、速查与极速刷题系统。深度挖掘并融合官方教程合集、历年真题（2009–2023）、考前四页纸、百条必背清单、易混淆辨析对与章节思维导图，支持自由调节剩余备考天数，并在备考时间 `< 10 天` 时自适应自动切换至“🔥 极限冲刺模式”。

---

## 🌟 核心亮点与系统特性

### 1. 动态可调备考周期引擎（8周基准体系 ⇄ `< 10天` 极限冲刺）
- **自由调节剩余天数 (1 ~ 56 天)**：用户可通过滑块或数字输入框随心设定距离考试的天数，或根据统考目标日期自动折算。
- **常规 8 周通关模式 ($\ge 10$ 天)**：遵循《软件设计师计划》三轮复习法：
  - **第一轮（第 1–3 周）**：基础通读与章节导图梳理；
  - **第二轮（第 4–6 周）**：上午专题与下午大题（DFD/数据库/UML/算法/设计模式）专项攻坚；
  - **第三轮（第 7–8 周）**：历年真题全真模考与查漏补缺。
- **🔥 极限冲刺模式（$< 10$ 天自动触发）**：
  - 一旦剩余天数调至 10 天以内（如 5 天、3 天、7 天），系统自动切换为 **Crash Sprint Mode**。
  - 遵循**二八法则**自动过滤低性价比生僻偏题，按 **Day 1 ～ Day $N$** 重排每日高分值夺分任务流。
  - 实时联动 **45/75 及格安全线雷达**，牢记“及格线哲学”：不求 70 分高分，只求双科稳过 45 分！

### 2. 五大现代化核心交互视图

| 视图模块 | 访问路径 | 核心能力与交互设计 |
|---|---|---|
| **自适应备考驾驶舱** | `/` | 剩余天数动态调节器、模式状态横幅、按天/按周任务打卡清单、完成度实时百分比、45/75 双科及格安全线雷达评估 |
| **考前精华速查中心** | `/cheatsheet` | 考前必备四页纸、软设知识点 100 条（支持背诵标记）、易混淆概念 35 组对比、8 大章节思维导图知识树、全局即时检索 |
| **3D 考点公式速记卡** | `/flashcards` | 107 张高频卡片、丝滑 3D 翻转交互（点击或空格翻转）、核心公式、秒杀口诀、考场避坑提示、9 大领域过滤与掌握打标 |
| **上午综合知识极速刷题** | `/practice` | 234 道全真真题/模考题、全键盘快捷键（`1-4`/`A-D` 选题，`Enter`/`Space` 提交，箭头切题）、错题自动入库、高频必刷筛选 |
| **专属错题本靶向重练** | `/mistakes` | 错题自动归集与靶向重测（无缝载入 Quizzer 极速重刷）、一键掌握移出、分类统计与清空支持 |
| **下午案例分析专项工坊** | `/cases` | 26 套全真案例、5 大必考题型全覆盖（DFD 5套、数据库 5套、UML 5套、算法 5套、设计模式 6套）、交互式填空作答、智能容错模糊评分、采分点抽屉 |

### 3. 严格的安全与键盘隔离机制
- **输入框全局快捷键物理隔离**：全局键盘引擎在检测到光标聚焦于 `input`、`textarea` 或任何 `contentEditable` 元素时，严格屏蔽刷题选择快捷键，确保在下午案例填空作答或关键词检索输入时绝对不误触发答题。
- **下午案例智能容错评分引擎 (`scoringHelper.ts`)**：自动归一化中英文符号（逗号、顿号、分号、冒号、括号、引号）、过滤多余空白符与大小写，智能支持斜杠（`/`）与“或”字分隔的别名同义词匹配。
- **本地持久化与清洁水合**：所有自定义天数、打卡清单、错题本、知识点与速记卡掌握状态、案例答案均持久化存入 `localStorage`（键名 `ruanshe-8weeks-v1`），并通过 `skipHydration` 结合客户端水合彻底杜绝 SSR 不一致报错。

## 🚀 极速本地启动

### 方式一：一键启动脚本（推荐）

在项目根目录下执行自带的启动脚本：

```bash
./start.sh
```

- 该脚本会自动检查 Node.js / npm 环境；
- 自动检测并安装缺失的 `node_modules`；
- 自动构建静态导出产物（`npm run build`）；
- 启动本地高性能服务并打印直达链接：`http://localhost:43180/ruanshe-8weeks/`。

若需指定端口或开启开发热重载模式：

```bash
# 自定义端口
PORT=8080 ./start.sh

# 开启 Next.js 开发热重载模式
./start.sh --dev
```

### 方式二：标准 npm 命令

```bash
# 1. 安装依赖
npm install

# 2. 生产构建（Next.js App Router 静态导出）
npm run build

# 3. 本地启动服务
node scripts/serve.mjs
```
